# Launch the "Rain Check" Shiny app

Opens an app that helps Sydney swimmers see how much recent rain raises
the chance that the water at their beach has high bacteria levels. The
app uses
[beach_samples](https://etc5523-2026.github.io/etc5523-assignment-4-abhignatippala/reference/beach_samples.md)
from this package, so no data files are read.

## Usage

``` r
run_app()
```

## Value

No return value; called to launch the app.

## Examples

``` r
if (interactive()) {
  run_app()
}
```
